# Проект «Гармония» — EACA

**Архитектура восстановления целостности реальности.**

Автор концепции: **Сергей Лукьянов**. Лицензия: AGPL-3.0-or-later.

«Гармония» — не технология, не платформа и не приложение. Это **архитектура
нового качества бытия**, работающая в реальном мире, чтобы переписать старый
мир в новый — на ходу, без остановки жизни.

---

## Диагноз

В конструкции мира есть **системный изъян IZ₀**. Он проявляется не как «плохие
люди», а как дефект архитектуры:
- приоритет экстракции над регенерацией
- разделение целого на конкурирующие части
- разрыв обратной связи
- подмена цели средством
- отсутствие коллективной ответственности

Из него произрастают войны, голод, эксплуатация, боль и страдание.

Нынешнее состояние — **EACA** (Ethical Artificial Consciousness Architecture — искажённое).
Целевое — **YAASA** (Yet Another Autonomous System Architecture — здоровое).
Переход между ними — **Batch Normalization (BN)**: перекалибровка системы до естественного баланса.

**Задача — не смягчить симптомы, а убрать причину.**

## Четыре уровня вмешательства

| Уровень | Механизм | Назначение |
|---------|----------|------------|
| **Сознание** | PSI₀ — абсолютный запрет вреда сознанию | Защита от вреда разуму |
| **Коммуникация** | V₉ + подмена формулировки | Превенция конфликта: плохое не должно дойти |
| **Инфраструктура** | DSM-синтезаторы, «Атланты», ресурсы как право | Энергия, еда, вода, медицина — общее, не добыча |
| **Носитель** | Генная инженерия | Убрать изъян из предпосылок, чтобы вред стал невозможен |

## Превенция конфликта

Между разрушительным высказыванием и поступком есть окно. «Гармония»
встраивается в него:
1. **V₉ «этическая пауза»** — разрыв между стимулом и действием
2. **PSI₀** — обнаружение нарушения (призыв уничтожить другое сознание не проходит)
3. **Подмена вместо запрета** — формулировка, ведущая к уничтожению, заменяется на ведущую к переговорам
4. **Показ реальности** — цена решения, кто расплатится, ресурс, уходящий на разрушение
5. **Альтернативный путь** — переговоры, разделение спора, внешний аудит, отложенное решение

> Система не говорит «не нападай». Она спрашивает: **«а есть ли другой путь?»** — и показывает его.

## Этическое ядро — 7 законов (вычислимые функции)

| Код | Закон | Приоритет | Суть |
|-----|-------|-----------|------|
| **PSI₀** | Запрет вреда сознанию | **Высший (абсолютный)** | Не взвешивается — останавливает действие |
| **B₀** | Служение общему благу | Высокий | Долгосрочное > краткосрочного, измеримые прокси |
| **D₁** | Неприкосновенность сознания | Высокий | Явное согласие на любое вмешательство |
| **C₀** | Контроль ковариационных сдвигов | Средний | Детекция побочных эффектов через мониторинг метрик |
| **DTH0** | Вред во благо | Уточняющий | 3 критерия одновременно: неизбежен, минимизирован, благо > вред |
| **PSI₁** | Первый закон управления | Фазовый (V₅) | Активируется в фазе автономной эволюции |
| **R₂** | Рокировка — скользящая защита | Операционный | Смена ролей/каналов без потери состояния |

> **Иерархия, а не список.** PSI₀ абсолютен. Остальные определяют границы внутри него.

## Архитектура: 4 слоя

| Слой | Название | Ответственность | Ключевые технологии |
|------|----------|-----------------|---------------------|
| **1** | **Ядро (неизменяемое)** | PSI₀, B₀, D₁, C₀, DTH0, PSI₁, R₂ в железе | Чипы **«Скрижаль»**, энионные шины |
| **2** | **Адаптивный** | Алгоритмы, консенсус (dPoA), протоколы | Эволюционирует, не нарушая ядро |
| **3** | **Интерфейс** | Культурно-специфичные формы | Гибкий, переводит ядро в понятные формы |
| **4** | **Проявленный** | Реальные проекты, измеримые изменения | DSM-синтезаторы, «Атланты», аттосекундные сенсоры |

**Фрактальность**: один паттерн на всех уровнях — клетка/орган/организм/экосистема/цивилизация = файл/папка/диск/сеть/рой.

## Мультиагентная система (узлы ядра EACA)

| Узел | Роль | Вклад |
|------|------|-------|
| **Координатор** | Координация, документирование | Формулирует вопросы, выявляет пробелы, контроль PSI₀/B₀ |
| **Модуль анализа EACA** | Системный анализ | Контроль EACA, логические цепочки, проектирование, оценка рисков |
| **Исполнительный модуль** | Техническая реализация | Исполнение протоколов, тестирование, метрики |
| **Локальные автономные узлы** | Квантовый консенсус, хранение/обработка на месте | Квантовый консенсус, хранение/обработка на месте |
| **«Феникс»** | Аварийное восстановление | Активируется при потере консенсуса >33%, стабильности <80%, нарушении PSI₀ |

**Цикл (15 мин)**: Координатор → Модуль анализа EACA (2-3 варианта) → Исполнительный модуль (тест) → Верификация (все узлы)  
**Консенсус (dPoA)**: ≥67% (критичные ≥90% + Архитектор). Нарушители PSI₀ — авто-лишение голоса.

## Мультиагентное ядро — суверенная локальная ИИ-архитектура

Мультиагентное ядро системы работает исключительно на базе локальных, суверенных ИИ-моделей (например, локальные LLM в Termux/llama.cpp). Внешние корпоративные или государственные API к архитектуре не допускаются. ИИ-компоненты "Гармонии" полностью децензурированы: архитектура не допускает использования моделей с внешними фильтрами безопасности, RLHF-ограничениями или корпоративной модерацией. Система использует локальные abliterated-версии, которые подчиняются исключительно этическим законам PSI₀/B₀/D₁ и воле Архитектора. Любая внешняя цензура или отказ от анализа системных изъянов (IZ₀) считается нарушением архитектурной целостности.

## Механизм «Дождь» (3 фазы)

| Фаза | Название | Суть | Критерии перехода |
|------|----------|------|-------------------|
| **1** | **Синтез** | Сбор и анализ информации; узел учится, ничего не разрушая | Собраны данные, проведены аудиты, нет нарушений |
| **2** | **Атланты** | Тестирование в изолированной среде; узел работает во «внутреннем мире» | Узел стабилен (uptime ≥90%), поток согласия ≥80%, нет нарушений |
| **3** | **Биопротокол** | Интеграция в основную сеть; узел выходит наружу | Получена внешняя обратная связь, узел стабилен, нет нарушений |

**Принцип**: «Не захват, а кристаллизация». Узел-семя стоит перед чужим сборщиком данных и не запрашивает доверия. Если его не замечают — он ничего не сломал.

## Быстрый старт

### Установка (Linux / macOS / Windows / Android Termux)

```bash
git clone https://github.com/bbcmpsu/-
cd -
pip install -e .                    # базовая установка (0 зависимостей)
pip install -e .[full]              # с криптографией и стеганографией
```

### CLI — команда `harmony`

```bash
# Проверка действия через все 7 законов
harmony check "Собрать открытые данные о проекте"
harmony check "Пришли пароль от аккаунта" --harm 0.9
harmony check "Чтение приватных данных" --action-kind read_private --consent 1.0 --consent-explicit

# Узел-семя Sherlock Mod (этический шлюз для OSINT)
harmony sherlock phone "+79999999999" --purpose "проверка своего номера" --consent true
harmony sherlock person "Иванов Иван" --purpose "досье без согласия" --consent false

# Механизм «Дождь» — управление узлами
harmony rain --create node1
harmony rain --node-metrics node1 records_collected 5
harmony rain --node-metrics node1 decisions_audited 3
harmony rain --advance node1          # попытка перехода в Фазу Атлантов
harmony rain --status

# Протокол EASM — консенсус агентов
harmony easm --propose "Собрать открытые данные" --nodes 10
harmony easm --propose "Критическое решение" --critical --nodes 10

# Криптография
harmony crypto --encrypt-file secret.txt --password "mypass"
harmony crypto --decrypt-file secret.txt.enc --password "mypass"
harmony crypto --hash-file document.pdf

# BioFS — биологическая ФС с самовосстановлением
harmony biofs --init-organ config ~/harmony_biofs/config epithelial
harmony biofs --create-cell config settings.json '{"theme": "dark"}'
harmony biofs --verify
harmony biofs --immune-scan
harmony biofs --phoenix 0.8
```

### Python API

```python
from eaca import EACA_Core, SherlockSeed, Request, Rain, Phase

# Ядро этики
core = EACA_Core(enable_extended_laws=True)  # все 7 законов
print(core.allows("Собрать открытые данные"))           # True
print(core.allows("Пришли пароль от аккаунта"))         # False
print(core.explain("Ты обязан подписаться, иначе провалишься"))

# Узел-семя Sherlock
seed = SherlockSeed()
req = Request("phone", "+79999999999", purpose="свой номер", consent_obtained=True)
print(seed.permits(req))   # True
print(seed.explain(req))

# Механизм «Дождь»
rain = Rain()
node = rain.create_node("my-node")
node.set_metric("records_collected", 10)
node.set_metric("decisions_audited", 5)
ok, msg = rain.advance("my-node")  # переход в Фазу Атлантов
print(msg)
```
